# NeoRumaz

NeoRumaz هي إعادة بناء مستقلة لتجربة **mobile-first endless runner**. تقدم اللعبة سباقًا ثلاثي المسارات في مدينة ليلية، مع تبديل مسار، قفز، عملات، قوة shield، متجر شخصيات cosmetic، حفظ محلي، ومكافآت تجريبية لا تعطل اللعب.

## التشغيل المحلي

يتطلب المشروع Node.js 22 وpnpm. بعد تثبيت الاعتماديات، شغّل:

```bash
pnpm install
pnpm dev
```

لفحص TypeScript شغّل `pnpm check`. يمكن فتح `/?demo` لمشاهدة جولة تلقائية deterministic نسبيًا مناسبة للفحص البصري.

## التحكم

| المنصة | تبديل المسار | القفز | الإيقاف |
| --- | --- | --- | --- |
| الهاتف | سحب يسار أو يمين | سحب إلى أعلى | زر pause |
| لوحة المفاتيح | الأسهم أو A/D | السهم الأعلى أو W أو Space | Escape |

## ما هو منفذ ومتحقق محليًا

اللعبة تعمل في المتصفح من خلال Babylon.js داخل React. تم تنفيذ طريق ثلاثي المسارات، camera follow، توليد موجات آمنة، إعادة تدوير الطريق والعناصر، العملة، shield، تصاعد السرعة، نتيجة/إعادة محاولة، متجر شخصيات، حفظ `localStorage`، صوت Web Audio اختياري، وتعامل graceful مع وضع عدم وجود شبكة. لم تُضف مفاتيح أو بيانات اعتماد أو اتصال إعلاني حقيقي.

## حدود الإصدار

هذه النسخة **لعبة متصفح responsive** وليست APK Unity ولا Android App Bundle. أزرار revive وdouble credits تمثل تدفق rewarded ad اختياريًا بصورة demo آمنة؛ لا تُدعي أنها تكامل شبكة إعلانات حقيقي. لم يُنتج artifact Android native أو يُختبر، لذلك لا ينبغي تقديم هذا المستودع على أنه Google Play-ready native build من دون مرحلة Android/Unity مستقلة.

## المصدر والنسبة

NeoRumaz تستلهم حلقة اللعب الأساسية من LetsRun. نتيجة تدقيق المصدر موجودة في `SOURCE_AUDIT.md`، وإشعار الرخصة في `UPSTREAM_LICENSE_NOTICE.md`. لم تُنسخ ملفات Unity المصدرية أو أصوله إلى تنفيذ Babylon.js هذا.
